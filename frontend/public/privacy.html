Privacy · last updated 29 October 2026

Your resume is not a dataset.

Resume Analysis processes a resume to score its fit for a role and to show evidence for that score. The API runs in memory on Google Cloud Run. No upload is written to disk, and no resume text is included in application logs.

What is processed

  • The uploaded PDF or DOCX, held in memory for the request only.
  • The target role and optional job description you provide.
  • Derived skills, education, experience, and scoring signals.

Hosting

The API runs on Google Cloud Run in the us-central1 region of the United States. Google Cloud processes requests in memory on our behalf and does not receive a stored copy from this application. Request metadata may appear in Google Cloud logs under Google's terms.

When AI review is enabled

AI review is off unless you explicitly tick the consent box. When enabled, high-confidence PII is redacted first: email, phone, URLs, profile handles, street addresses, and a conservative name heuristic. The redacted text is then sent to OpenCode Go:

  • Beam Free is the primary model. Its provider does not train on requests and retains them for 30 days for safety.
  • GLM-5.3-Flash is the fallback. Its provider reports zero-day retention and does not train on requests.
  • Iceman Contributor Free is not used because it trains on prompts and completions.

Redaction reduces risk but is not a guarantee. Do not upload a resume unless you have the right to process it.

Retention

This application does not persist resumes, results, or history. In-memory request state is discarded after the response. Google Cloud Run request logs are retained under the project's Cloud Logging policy; resume text is not written to those logs. OpenCode Go's model retention is described above and is governed by OpenCode's policies.

Your choices

  • Leave AI review unchecked to use local scoring only.
  • Use a redacted or fictional resume for a demo.
  • Do not upload a resume if you are not authorised to process it.

DPDP Act and GDPR

This is a portfolio demo, not a hiring decision system. It follows data minimisation and purpose limitation: process the minimum text needed for the requested analysis, do not store it, and ask for consent before any external transfer. Google Cloud Run (United States) hosts the API, and OpenCode Go handles optional AI review; both are subprocessors. If you deploy it for real candidates, add a lawful basis, a notice, a retention policy, a deletion path, and a cross-border transfer review appropriate to your jurisdiction. This page is not legal advice.
